# موقع شركة مسار للمشاريع والتطوير السعودية

## محتويات المجلد
- `index.html` الصفحة الرئيسية (المسارات، الرسوم، نموذج الطلب)
- `about.html` من نحن · `policy.html` سياستنا · `privacy.html` الخصوصية · `security.html` الأمان · `thanks.html` صفحة ما بعد الدفع
- `assets/config.js` **الإعدادات التي تعدّلها أنت**
- `assets/data.js` بيانات المسارات والرسوم (للعرض فقط)
- `api/create-invoice.js` دالة إنشاء الفاتورة لمنصة Vercel
- `create-invoice.php` نفس الدالة للاستضافات العادية (PHP)
- `assets/fonts/` الخطوط (مرخصة OFL ومحلية، لا تُحمَّل من طرف خارجي)

## كيف يعمل الدفع
1. العميل يعبّئ النموذج ويضغط «الانتقال إلى الفاتورة والدفع».
2. المتصفح يرسل اسم المرحلة وبيانات العميل إلى دالة الخادم (لا يرسل أي مبلغ).
3. الخادم يحدد المبلغ من جدول الأسعار عنده، وينشئ فاتورة لدى ميسر فيها اسم العميل وجواله ونوع الخدمة والمبلغ ورقم الطلب.
4. العميل يُنقل إلى صفحة الفاتورة المستضافة لدى ميسر (`checkout.moyasar.com`) ويدفع هناك.
5. بعد الدفع يعود إلى `thanks.html`. الإثبات الحقيقي هو إشعار ميسر والفاتورة في لوحتك، وليس هذه الصفحة.

لا توجد قاعدة بيانات في الموقع. المراحل «حسب الاتفاق» لا تمر بالدفع، بل تُرسل عبر واتساب.

## خطوات التشغيل
### 1) عدّل `assets/config.js`
- `WHATSAPP` رقمك بالصيغة الدولية `9665XXXXXXXX`
- `EMAIL` و`PHONE` و`CR_NUMBER` و`VAT_NUMBER` (تظهر في أسفل الموقع إن وُجدت)
- `INVOICE_ENDPOINT`: `/api/create-invoice` لـ Vercel، أو `/create-invoice.php` لاستضافة PHP
- `VAT_PERCENT`: اتركه 0 إن كانت الرسوم المعلنة نهائية، أو 15 إن كانت الضريبة تُضاف فوقها. **يجب أن يطابق قيمة الخادم.**

### 2) انشر الموقع والدالة (اختر واحداً)
**أ) Vercel:** ارفع المجلد كمشروع، ثم أضف متغيرات البيئة:
- `MOYASAR_SECRET_KEY` = المفتاح السري من لوحة ميسر (`sk_test_...` للتجربة)
- `SITE_URL` = رابط موقعك `https://www.masarpdt-sa.com` (بدون شرطة أخيرة)
- اختياري: `VAT_PERCENT` و`INVOICE_EXPIRY_HOURS`

**ب) استضافة PHP:** ارفع المجلد كاملاً. اضبط `MOYASAR_SECRET_KEY` و`SITE_URL` كمتغيرات بيئة، أو اكتبهما في أعلى `create-invoice.php`. لا تضع المفتاح السري في أي ملف JavaScript أو HTML.

### 3) جرّب بمفاتيح الاختبار
أنشئ طلباً تجريبياً وتأكد أن صفحة الفاتورة تعرض الاسم والخدمة والمبلغ الصحيح، ثم أتمم دفعاً تجريبياً وتأكد من العودة إلى `thanks.html` ومن ظهور الفاتورة في لوحة ميسر. بعدها بدّل إلى `sk_live_...`.

### 4) قبل الإطلاق (يخصك أنت)
- راجع نص «الإلغاء والاسترجاع» في `policy.html`، فقد كتبته بصياغة عامة وعليك استبداله بسياستك الفعلية.
- اعرض صفحات السياسة والخصوصية على مختص نظامي.
- فعّل HTTPS، وأضف رابط `canonical` في وسم `<head>` لكل صفحة.
- إن أضفت تحليلات أو إعلانات أو أي خدمة خارجية، حدّث صفحتي الخصوصية والأمان لأنهما تنصان حالياً على عدم وجودها.
- ميسر قد يطلب منك رابط الشروط وسياسة الاسترجاع والسجل التجاري عند تفعيل الحساب.

## الرفع والمزامنة مع GitHub
المستودع: https://github.com/pdtyk7-oss/pdt.yk7-gmail.com.git (فارغ حالياً وعام).

**الرفع الأول** (من جهازك، داخل مجلد الموقع):
```
git init -b main
git add -A
git commit -m "موقع شركة مسار: النسخة الأولى"
git remote add origin https://github.com/pdtyk7-oss/pdt.yk7-gmail.com.git
git push -u origin main
```
عند الطلب أدخل اسم المستخدم، وكلمة المرور تكون **Personal Access Token** من GitHub (Settings ← Developer settings ← Personal access tokens) بصلاحية `repo` على هذا المستودع فقط. لا تشارك التوكن مع أحد.

**المزامنة:** أي تعديل لاحق:
```
git add -A && git commit -m "وصف التعديل" && git push
```
**النشر التلقائي:** في Vercel اختر Add New ← Project ← Import من هذا المستودع، وأضف متغيرات البيئة (`MOYASAR_SECRET_KEY` و`SITE_URL`). بعدها كل `git push` ينشر الموقع تلقائياً.

**تنبيه:** المستودع عام، فكل ما فيه يراه الجميع. لا تضع المفتاح السري لميسر في أي ملف، فقد أضفت `.gitignore` يستبعد ملفات `.env`، والمفتاح مكانه إعدادات Vercel فقط.
